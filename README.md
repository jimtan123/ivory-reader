# Ivory Reader

A single-file piano trainer for beginners. Open `index.html` in a browser, or use the GitHub Pages site.

- **Read notes**: staff flashcards answered on an on-screen keyboard, by computer key, or on a MIDI piano.
- **Hand position**: C, Middle C and G positions with finger numbers, posture checklist, finger drill.
- **Practice**: pieces written in a short text notation, rendered on a grand staff, with Listen and Wait modes.
- **Metronome** and **MIDI** in the bottom bar.

MIDI needs Chrome or Edge on a laptop or Android tablet. Progress and saved pieces stay in the browser.
